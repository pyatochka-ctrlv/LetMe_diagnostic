# Острів суперсил — діагностика життєвих навичок

Індивідуальний онлайн-урок на ≈45 хв для дітей 7–8 і 9–10 років. Дитина мандрує островом із 7 локаціями, а вчитель веде урок з окремого пульта.

| Файл | Для чого |
|---|---|
| `pult.html` | **Пульт вчителя — не демонструвати.** Налаштування, сценарій поточного кроку, кнопки введення, пропуски, звіт для батьків, PDF, надсилання в таблицю. |
| `index.html` | **Вікно гри «Острів суперсил»** — його вчитель демонструє в Zoom. Лише те, що бачить дитина. |
| `scenariy.html` | Повний сценарій для друку (перемикачі групи й версії А/Б). |
| `config.js` | Увесь контент, тексти, пороги, версії. Правте тут. |
| `core.js` | Стан, логіка станцій, оцінювання, синхронізація, самотести. |
| `hero-pixel.js` | Піксельний рушій персонажів (герой, Іскра, Боб, котики, вирази облич). |
| `sprites.html` | Службова сторінка для перевірки спрайтів (не для уроку). |
| `google-apps-script.gs`, `GOOGLE_SHEETS.md` | Надсилання результатів у Google Таблицю. |

## Як провести урок

1. Відкрий `pult.html` у Chrome або Edge.
2. Заповни налаштування: ім’я дитини (лише ім’я), своє ім’я, групу, вік, стать (для форм слів «мріяв/мріяла»), версію: **А — вхідна**, **Б — повторна**.
3. Натисни **«Відкрити вікно гри»**. Якщо браузер заблокував вікно — дозволь спливні вікна для сайту або відкрий `index.html` вручну **в тому самому браузері**.
4. Перетягни вікно гри на екран, який демонструватимеш, і один раз клікни в ньому: так браузер дозволить звук.
5. Коли на пульті з’явиться «Вікно гри підключено», у Zoom → «Демонстрація екрана» обери **тільки вікно «Острів суперсил»**, не весь екран. Вікна легко розрізнити за назвами: «Острів суперсил» і «Пульт вчителя — не демонструвати».
6. «Почати урок». Далі читай картку «Скажи дитині», вводь, що каже дитина, і тисни «Далі» (Enter).
7. Після фіналу пульт відкриває звіт для батьків: «Зберегти PDF». Якщо налаштовано таблицю, результати надсилаються туди самі.

**Гарячі клавіші пульта:** Enter — «Далі»; пробіл — «+1 спосіб» у Кіностудії; Ctrl+Z — «Стерти останнє».
**Меню «⋯»:** «Нова діагностика» (з підтвердженням), «Відкрити вікно гри ще раз», звук у грі.

### Обмеження

- **Пульт і гра мають бути відкриті в одному браузері на одному комп’ютері.** Вони спілкуються через `BroadcastChannel` і `localStorage`, тому різні браузери чи пристрої один одного не побачать.
- Перезавантаження будь-якого з вікон прогрес не губить: стан зберігається в `localStorage`, а гра після завантаження сама запитує його в пульта.
- «Нова діагностика» стирає поточний стан. Перед нею збережи PDF.

## Як змінити тексти й пороги після пілоту

Усе лежить у `config.js`:

- `CONFIG.thresholds` — пороги рівнів усіх проб. Наприклад, `emotions.frames['78'] = { l3: 5, l2: 3.5 }` означає: сума ≥5 → рівень 3, ≥3,5 → рівень 2, інакше 1.
- `CONFIG.versions.A` / `CONFIG.versions.B` — контент станцій (кадри, фрукти, товари, речі, репліки Боба, картки, питання). Структура обох версій однакова.
- `CONFIG.script` — що казати й робити на кожному кроці (пульт і `scenariy.html`).
- `CONFIG.codes` — коди на пульті з еталонними відповідями (кнопка «Приклади»).
- `CONFIG.skills[*].levels` — тексти звіту для батьків за рівнями.
- `CONFIG.iskra` — репліки Іскри в грі.
- `CONFIG.heroStyle` — `'b'` (чібі-звірятко) або `'a'` (герой у костюмі).

Для калібрування в Google Таблиці є рівні кожної проби, тривалість кожної станції й повні сирі дані (останні колонки).

## Самотести й перевірка

- `pult.html?test=1` — самотести логіки, результати в консолі браузера (F12).
- `sprites.html` — усі голови в обох стилях з кожним предметом окремо й у повному костюмі, Боб, котик, Іскра й 14 виразів облич.

## Деплой на GitHub Pages

1. Репозиторій → **Settings → Pages**.
2. **Source:** «Deploy from a branch», гілка `main`, папка `/ (root)` → **Save**.
3. За 1–2 хв: пульт — `https://<користувач>.github.io/LetMe_diagnostic/pult.html`, гра відкривається з пульта, сценарій — `.../scenariy.html`.

Якщо репозиторій приватний, GitHub Pages потребує платного плану. Інакше репозиторій має бути публічним.
