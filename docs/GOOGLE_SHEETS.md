# Результати в Google Таблиці й PDF на Google Диску

Коли МІК уперше відкриває «Звіт для батьків», пульт сам:

1. генерує PDF звіту в браузері (бібліотека html2pdf.js 0.10.1 з cdnjs);
2. надсилає один рядок (формат НМТ) разом із PDF у спільну Google Таблицю.

Скрипт кладе PDF у вашу папку на Google Диску й записує посилання на нього в колонку «PDF результату».

## ⚠️ Спершу про дані дітей

- У таблиці й папці зберігаються **ім’я та прізвище дитини**, вік, стать і результати. **Таблиця й папка мають бути доступні лише команді.** Не вмикайте доступ «усім, хто має посилання» й не пересилайте їх за межі команди.
- Скрипт **нічого не відкриває публічно**: кожен PDF отримує доступ від папки, у яку його збережено. Хто має доступ до папки, той бачить і PDF.
- Токен — це спільний пароль. Його видно в коді сторінки, тож він захищає лише від випадкових і сміттєвих записів. Якщо токен витік, замініть його в обох місцях (кроки 3 і 6).

## Крок 1. Створіть таблицю

1. Відкрийте [sheets.new](https://sheets.new) під командним Google-акаунтом.
2. Назвіть таблицю, наприклад, «Острів суперсил — проходження».
3. **Поділитися** → додайте лише членів команди. Загальний доступ: «Обмежений».

Аркуш створювати не треба: скрипт сам додасть аркуш «Проходження» з рядком заголовків.

## Крок 2. Створіть папку для PDF

1. На [Google Диску](https://drive.google.com) під тим самим акаунтом: **Створити → Нова папка**, наприклад, «Острів суперсил — PDF».
2. **Поділитися** → лише члени команди. Загальний доступ: «Обмежений».
3. Відкрийте папку й скопіюйте її ID з адреси. Це частина після `/folders/`:
   `https://drive.google.com/drive/folders/`**`1AbCdEfGhIjKlMnOpQrStUvWxYz`**

## Крок 3. Вставте скрипт

1. У таблиці: **Розширення → Apps Script**.
2. Видаліть увесь код у `Code.gs` і вставте вміст файлу [`apps-script/Code.gs`](../apps-script/Code.gs).
3. Замініть значення:
   - `const TOKEN = '…'` — довгий випадковий токен (30–40 латинських літер і цифр). Запишіть його: він знадобиться на кроці 6.
   - `const FOLDER_ID = '…'` — ID папки з кроку 2.
4. 💾 **Зберегти**.

## Крок 4. Розгорніть як веб-застосунок

1. **Розгорнути → Нове розгортання** → ⚙️ → **Веб-застосунок**.
2. **Виконувати від імені:** «Я». **Хто має доступ:** «Усі». Пульт працює без входу в Google, тому без цього він не зможе надсилати дані. Таблиця й папка при цьому лишаються закритими: доступ «Усі» стосується лише адреси скрипта, яка приймає запис із правильним токеном.
3. **Розгорнути** → **Надати доступ** → акаунт → «Додатково» → «Перейти до … (небезпечно)» → **Дозволити**. Скрипт просить доступ до таблиці й до Диску, щоб зберігати PDF.
4. Скопіюйте **URL веб-застосунку** (закінчується на `/exec`). Якщо відкрити його в браузері, має з’явитися `{"ok":true,…}`.

## Крок 5. (Необов’язково) Перевірте запис вручну

```js
function testPost() {
  const e = { postData: { contents: JSON.stringify({ token: TOKEN, id: 'test-1', headers: ['Ім’я', 'PDF результату', 'id'], row: ['Тест', '', 'test-1'], fileName: 'Тест.pdf', pdf: null }) } };
  Logger.log(doPost(e).getContent());
}
```

Після перевірки видаліть тестовий рядок, функцію й тестовий аркуш, якщо він з’явився.

## Крок 6. Вставте URL і токен у config.js

```js
sheets: { endpoint: 'https://script.google.com/macros/s/…/exec', token: 'ваш-токен-з-кроку-3' },
```

Закомітьте й запуште: GitHub Pages оновиться за 1–2 хвилини. Поки `endpoint` порожній, пульт нічого не надсилає.

## Як це працює

- **Коли.** Рядок і PDF надсилаються при першому відкритті звіту. Повторне відкриття звіту нічого не надсилає вдруге.
- **Без дублів.** Кожне проходження має прихований `id` (остання колонка, прихована). Якщо той самий `id` надійде ще раз, скрипт оновить рядок, а старий PDF цього проходження перенесе в кошик.
- **Назва PDF:** «Прізвище Ім’я — дд.мм.рррр.pdf».
- **Без інтернету.** Рядок лишається в черзі браузера (localStorage) і надсилається, щойно пульт знову відкриють на цьому комп’ютері. Якщо PDF не вміщається в localStorage, у черзі лишається лише рядок, а PDF генерується заново при повторі (поки відкрито звіт). Під звітом видно статус: «Надіслано ✓» або «Не надіслано — повторити».
- **Якщо html2pdf.js не завантажився** (немає доступу до cdnjs), рядок однаково надсилається, а колонка «PDF результату» лишається порожньою. Тоді PDF можна зберегти кнопкою «Зберегти PDF» і покласти в папку вручну.
- Через `no-cors` пульт не бачить відповіді скрипта. «Надіслано ✓» означає, що запит пішов у мережу. Якщо рядка немає, перевірте токен, FOLDER_ID і доступ «Усі».
- Одночасні надсилання від кількох МІКів записуються по черзі (LockService).

## Колонки аркуша «Проходження»

| № | Колонка | Що в ній |
|---|---|---|
| 1 | Дата й час | початок уроку, `дд.мм.рррр гг:хх:сс` |
| 2–3 | Ім’я, Прізвище | обов’язкові поля пульта; за прізвищем зручно шукати |
| 4–7 | Вік, Вікова група, Стать, МІК | група: «7–8» або «9–10» |
| 8 | Тривалість, хв | від «Почати урок» до фіналу, 1 знак після коми |
| 9–22 | «Навичка — результат», «Навичка — що робити» | по 2 колонки на кожну з 7 навичок. Результат: `🟡 Росте · 🟢 Кадри: 6 з 6; 🔴 Способи заспокоїтися: 0`. Що робити: 2 вправи вдома. Фон клітинки результату — колір рівня |
| 23 | Самооцінка | `Емоції 2/3 \| Сейф 3/3 \| …`; «—» для непройдених навичок |
| 24–26 | Кількість 🟢 / 🟡 / 🔴 | скільки проб отримали кожен рівень |
| 27 | Усі відповіді | коди відповідей по пробах (формат — у [README](../README.md#формат-колонки-усі-відповіді)) |
| 28 | Загальний висновок / маршрут | сильні сторони, з чого почати, маршрут (окремими рядками) |
| 29 | PDF результату | посилання на PDF у папці (доступ — як у папки) |
| 30 | id | прихований ідентифікатор проходження для дедуплікації |

Кольори: 🟢 3 — сильна, 🟡 2 — росте, 🔴 1 — прокидається, ⚪ не оцінено (станцію пропущено).

## Якщо змінили скрипт

**Розгорнути → Керувати розгортаннями → ✏️ → Версія: «Нова версія» → Розгорнути.** URL лишається тим самим.
